# cityshield-ai
AI-powered real-time cyber risk detection for smart city infrastructure, scores threats by civic impact, not just technical severity. Built for Smart Horizon 2026 Hackathon.
CityShield ingests live telemetry from smart city assets — traffic systems, hospitals, utilities — and uses ML-based anomaly detection to flag threats. Unlike generic SIEM tools, it scores risk by civic impact, not just technical severity: a compromised hospital system outranks a compromised parking sensor, even with identical anomaly scores.

Built by Team MIRAI for Smart Horizon 2026: 48-Hour International Hackathon, New Horizon College of Engineering.

Stack: FastAPI · React + Leaflet.js · scikit-learn (Isolation Forest) · PostgreSQL · WebSockets
